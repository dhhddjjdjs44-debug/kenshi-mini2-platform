# 5. Диагностика: что делать и что считать результатом

Сначала прочитать актуальное состояние. Все hardware тесты — только после
отдельной проверенной установки кандидата и согласованной аппаратной пробы.
PC Preview содержит тестовые значения, а не доступ к подключённому телефону.

## Навигация

DIAGNOSTICS,4/6 или влево-вправо перелистывают шесть страниц, правая софт назад.
На страницах с тестом OK/левая софт/5 запускают один явный запрос. Сам просмотр,
render/удержание/idle его не запускают; смена страницы не должна запускать тест.
ASSETS и PROFILE — страницы просмотра, не дополнительные исполнительные тесты.

| Страница | Смысл и честная интерпретация |
|---|---|
| SOUND/PCM | Аналоговый snapshot8 регистров. Не тон/не PCM-driver; DSP domain не включается |
| MOTOR TEST | Старый ограниченный 50ms PMU probe. Уже был физический отказ, не рабочий haptic HAL |
| CPU TEST | TCM EST MHZ; оценка с условиями, не exact CPU clock |
| KEY CAPTURE | Мастер 21 клавиши, raw/ожидаемая/фактическая |
| ASSETS | Read-only состояние pack/ресурсов; не запись на карту |
| PROFILE US | Последние game UPDATE/CONVERT/LCD DMA/FPS×10; не замер MHz |

## Полный проход KEY CAPTURE

1. Открыть страницу KEY CAPTURE и запустить OK.
2. Отпустить ВСЕ клавиши, дождаться `PRESS THIS KEY`.
3. Нажать только названную в EXPECT клавишу, подержать до фиксации HELD.
4. Сравнить DETECTED и contact с физической кнопкой; снять фото при расхождении.
5. Полностью отпустить. Только release фиксирует запись; `RELEASED SAVED`
   и интервал обратной связи предшествуют следующему шагу.
6. Последовательно: UP, DOWN, LEFT, RIGHT, OK, левая soft, правая soft, CALL, END,
   1,2,3,4,5,6,7,8,9, *,0, #.
7. END — только короткий tap. Если нет отдельного контакта или есть риск выключения,
   пропустить, а не удерживать power.
8. `0+#` коротко и полностью отпустить — пропустить текущий шаг.
   `0+#` держать не менее 1,2s — выйти. Не использовать произвольный BACK:
   внутри мастера BACK/OK/CALL сами измеряются и не управляют оболочкой.
9. После 21 шага `CAPTURE COMPLETE`;2/8 просматривают результаты.
10. Таблица остаётся **только в RAM**, не remap, не запись NV/SD.
    Для применения нужны анализ снимков, правка единой карты, сборка и проверка.

`MULTI/ROLL RETRY` — несколько/сменившихся контактов; `DUPLICATE RETRY` — повтор
ранее записанного контакта. Это не основание молча принять первый попавшийся бит.
Контакт 255 означает unknown/multi sentinel, а не реальную кнопку.

## CPU TEST

Новый probe: A=SUBS/BNE, B=ADD/SUBS/BNE, N65536 и 2N, три серии, дифференциальный
расчёт в прежнем 16B TCM scratch. Исходные слова восстанавливаются на выходах.
Допущения: GPT26MHz и zero-wait ARM7 циклы 4/5. Проверяются согласование, ход GPT,
checksum, clock drift и maskedIRQ/FIQ. Probe не меняет PLL/cache/EMI/voltage.

UI `EST MHZ` означает **оценку**, exactHz остаётся 0. Порог согласования 2% — не
гарантированная абсолютная погрешность 2%. `TCM REJECTED`/UNKNOWN — отказ, его
не превращают в 260MHz по похожему raw регистру. Старый MIN MHZ — лишь lower bound.
Снять весь экран с EST/TCM delta/reference/reason. Результата на телефоне пока нет.
Сходящиеся 60 секунд показывают правильность часов времени, не частоту CPU.

## MOTOR TEST и SOUND

Не запускать motor-test многократно «пока не завибрирует». Он не автономный
one-shot и не защита от зависшего CPU/шины. Старый enable/readback/off уже НЕ дал
ощутимого вибро. Батарея сейчас есть, но её наличие в том тесте неизвестно.
Рабочий стоковый маршрут мотора идёт через audio/DSP override, generic PMU ему
не равен. Не менять voltage/discharge/calibration наугад.

Звук проверяется ушами на динамике при известном тестовом сигнале и контролируемой
громкости; программный PCM/modelACK/readback за звук не считать. Для positive
reference использовать stock-аудиоплеер, не змейку с неясным звуком.

## PROFILE US

FPS×10 — телеметрия выводов кадров приложения, не обязательно уникальные игровые
тики Doom и не частота ядра. UPDATE/CONVERT/LCD DMA — длительности этапов;
снимок игры сохраняется при переходе в меню. Синтетические значения fixture не
считать новым приростом производительности на телефоне.
