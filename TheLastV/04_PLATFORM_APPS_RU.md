# 4. Launcher, игры, телефонный режим и плееры

Речь о реализованной оболочке кандидата/предпросмотра. Сейчас телефон работает
на stock; это не инструкция, будто новая оболочка уже прошита.

## HOME

Пять пунктов: GAMES, PHONE, MUSIC, VIDEO, DIAGNOSTICS.
2/8 или крестовина вверх/вниз меняют выбор, OK/левая софт открывают.
Правая софт возвращает на уровень выше; в HOME ничего не закрывает.

## GAMES

YOUR GAME — независимый образец своей игры. Для Doom нужна сборка `doom`,
его законно полученный DOOM1.WAD и парный loader. В `sdk` Doom не нужен.
В GAMES вверх/вниз переключают выбор; OK запускает. При выходе из своей игры
и повторном запуске пример инициализируется заново. Doom при выходе приостанавливается,
при повторном выборе продолжает сессию. Сохранения на носитель не реализованы.

Запуск/выход останавливает или передаёт владение media/audio/haptic через общий
lifecycle. Не выдавать отдельные приложения за независимые динамические ELF:
сейчас своя игра связана в общий PLAT.ELF.

## PHONE — демонстрация

1. Открыть PHONE.
2. Набрать непустую последовательность цифр/*/#, максимум 24 символа.
3. Нажать OK/левую софт или вызов: отображается экран ID.
4. Последовательность `*#06#` открывает этот экран автоматически.
5. На экране набора правая софт удаляет по одному символу; когда строка пуста,
   возвращает HOME. На экране ID правая софт возвращает к набору.

Это демонстрационный интерфейс, НЕ сотовая связь/набор реального абонента/SMS.
ID показывается только из отдельно подтверждённого владельцем `PHONE.ID`:
15ASCII цифр, Luhn, type4 в KDATA.PAK. Неподтверждённые цифры не генерировать.
Сейчас такого подтверждённого ID в образце нет: `UNAVAILABLE / STOCK CHECK DUE`
нормальны. `ID FROM CONFIG` не означает извлечение/проверку NV. Реальный IMEI/NV
никогда не менять. Файлы с ID не публиковать.

Время: RTC при успешном согласованном чтении, иначе UPTIME; UPTIME — время с
начала работы, не часы внешнего мира и не частота процессора.

## MUSIC

Программный плеер перечисляет WAV-ресурсы type2 **в KDATA.PAK**, а не My Music.
-4/6/крестовина влево-вправо — предыдущая/следующая запись;
- OK/5 — pause/resume; после EOF повторный старт с начала;
-2/8/вверх-вниз — громкость 0..8;
- правая софт — stop и HOME.

Физического sink сейчас нет: K_UNSUPPORTED / NO AUDIO DRIVER / PCM NO SINK —
ожидаемый blocker. Ползунок, двигающийся курсор, PCM-буфер или надпись PLAYING
не подтверждают звук из динамика. Заводской плеер — отдельная реализация stock.
157MP3 на карте пока не становятся доступными custom автоматически.

## VIDEO

Перечисляет KVID type3 в KDATA.PAK. Кнопки те же:4/6 смена, OK/5 пауза/продолжение,
2/8 громкость, правая софт выход; EOF удерживает последний кадр, повторный старт
начинает ролик заново. Это последовательность кадров, не загрузочный PNG.

Без физического PCM/played cursor видео работает **SILENT**. MP4/H.264 и MP3
не декодируются телефоном; подготовка выполняется на ПК. Реальные FPS/AVsync не
подтверждены. Пропуски кадров считаются; не оценивать CPU по скорости PC Preview.

## Стандартные ограничения UI

Текстовый шрифт uppercase ASCII7×7 с шагом 8px, русский шрифт не добавлен.
Нет универсального автоповтора меню. Для движения игра использует held,
для действий — pressed, для отпусканий — released.
