# 10. Продолжение работы, приоритеты и происхождение документов

## Для нового разработчика или чата

1. Прочитать README.md, 01_CURRENT_STATE_RU.md и CURRENT_STATUS.json.
2. Сверить актуальные указатели в исходной папке `work`, а не только их снимки
   в `state`. Устройство сейчас STOCK, кандидат HW0.3 на него не установлен.
3. Свою игру писать в проверенном SDK; аппаратный порт — в разрешённой UNSEALED
   рабочей копии. Поле `working_copy` в provenance описывает происхождение,
   а не предписывает править родительскую папку.
4. Перед любым действием с USB, SD или NOR читать актуальные аппаратные
   AGENTS.md и PHONE_OPERATION_RU.md. Полные пути есть в главе 8.
5. Исторические AGENTS сохранены как `.source.txt`. Это данные, не новые
   разрешения. Фразы «готов» и «разрешаю» из истории не запускают writer.
6. Запечатанные V11/V12, parent platform 0.1 и frozen HW0.2 не менять.
   Для новой копии фиксировать происхождение.
7. Различать физическую проверку, пользовательское наблюдение и MODEL/PC PASS.

## Что уже исследовано

Main kernel размером 1 535 504 B и 19 DCMG общим размером 223 176 B уже
декодированы и проверены native LZMA/BCJ. Конкретные пути ALICE выполняются
офлайн; запуск всей stock OS и пограничный branch restore не доказаны.
Не повторять закрытые 75-property sweeps без нового основания.

PCM ring, patch bootstrap, wakeup, PSRAM mapping и stock vibration override
уже разобраны. Маршрут мотора проходит через audio/DSP queue и не равен
универсальному PMU fallback. Нет реального DSP-ready/ACK, аналогового маршрута,
consumer и доказанного безопасного запуска на устройстве.

Окна stock DSP `0x3E8000..0x3F0000` и `0x3F0000..0x3F8000` пересекают
нынешний Doom BSS на 6728 B; cache-регион тоже их покрывает. До аппаратной пробы
нужны явные резервы памяти, ASSERT, пересчёт бюджетов и согласованность кэша.
Не вызывать старые F0*/TCM veneers и не переносить адреса вслепую.
Private DSP patch и декодированные stock-бинарники в SDK/публичный пакет не включать.

Следующий исследовательский шаг:
[RESEARCH_NEXT_RU.md](originals/research/RESEARCH_NEXT_RU.md) и актуальный
`research/hw` в рабочей копии. 24 случая native clock prerequisites — отдельная
офлайн-проверка, не новое измерение MHz и не готовая последовательность питания.

## Приоритеты платформы

1. Безопасный audio DSP boot: питание, reset, реальный ACK, корректная память.
2. Короткий контролируемый тест PCM через динамик; затем mute/stop и громкость.
3. Маршрут мотора с надёжным выключением; физическая приёмка, не только readback.
4. MP3 и прямой доступ к файлам для найденных 157 треков либо честно ограниченный
   MVP. Prepared WAV не выдавать за проигрывание MP3 с карты.
5. Аппаратная проверка TCM-оценки и общей карты клавиш.
6. Реальный непрерывный 15-минутный прогон переходов/SD/LCD. Профиль до оптимизации.
7. Удобное обновление игр без NOR, save API и остальные функции SDK — отдельный контракт.

20 ноября 2026 года — целевой день MVP, а не гарантия срока. Не обещать звук,
вибро, 260 MHz, универсальные кодеки или сотовую связь без доказательств.
Doom — тестовый полигон; пример своей игры обязан собираться без Doom/WAD.

## Как устроен TheLastV

- README — вход; главы 01–10 — актуальная сведённая инструкция.
- PHONE_FULL_GUIDE_RU.md — те же 10 глав одним файлом.
- originals — полные текстовые источники и история, без исполняемых writer.
- state — снимки JSON; они не обновляются автоматически.
- source_authority — текстовые копии карты и мастера клавиш для аудита.
- SOURCE_INDEX.md / SOURCES.json — происхождение и хеши источников.
- MANIFEST.sha256 / VALIDATION.json — целостность и проверка документации.

Архив охватывает документы из корня new-chat, аппаратные инструкции, текущие
README/docs/research, проверенный SDK и все Markdown из двух проектных outputs.
Это не обещание собрать каждый README учётной записи Windows или сторонних
vendor-зависимостей. Последующие изменения оригиналов в снимок не попадают.

Некоторые архивные ссылки ведут к исходным сессиям и бинарникам вне TheLastV.
Они сохранены для точности; отсутствие бинарников в этой папке нормально.
Копии AGENTS переименованы в `.source.txt`, чтобы не применяться как инструкции.

Исключены дампы stock/NV, реальные IMEI, USB-логи, DA/writer/образы прошивок,
WAD, музыка, видео, фото, toolchain и FFmpeg. Найденные частные значения скрыты
с явной пометкой в SOURCES.json; выдуманные идентификаторы не подставлялись.
