# 3. Кнопки и управление

Эта таблица относится к **новой общей карте кандидата HW0.3 и SDK**, не является
гарантией совпадения всех прежних V11/V12 или заводского UI. На телефоне сейчас
stock; новая карта ещё требует повторной проверки после отдельной установки.

## Физическая карта

Источник: фото пользователя от 20 ноября; authority в `sdk/include/k_keys.h`.
«Контакт» — десятичный номер бита в пяти active-low 16-битных словах, НЕ сканкод
ПК, НЕ hex-маска и НЕ частота. Ненажатый контакт имеет raw-бит 1, нажатый —0.

| Клавиша | Контакт | Логическое действие SDK |
|---|---:|---|
| Вверх |39| K_UP |
| Вниз |15| K_DOWN |
| Влево |21| K_LEFT |
| Вправо |30| K_RIGHT |
| Центральная OK |42| K_CONFIRM |
| Левая софт-клавиша |33| K_CONFIRM |
| Правая софт-клавиша |72| K_BACK |
| Вызов |24| K_CALL |
| Завершение/Power |не установлен| Не угадывать, долгим удержанием не тестировать |
|1|27| Цифра 1 |
|2|0| Цифра 2 + K_UP |
|3|51| Цифра 3 |
|4|12| Цифра 4 + K_LEFT |
|5|13| Цифра 5 + K_ACTION |
|6|57| Цифра 6 + K_RIGHT |
|7|6| Цифра 7 |
|8|9| Цифра 8 + K_DOWN |
|9|48| Цифра 9 |
|*|3| Символ* |
|0|45| Цифра 0 |
|#|54| Символ# |

`END=255` в коде — sentinel UNKNOWN, не настоящий контакт 255.
UP не должен означать BACK. Несколько физических клавиш могут давать один
логический бит: отпускание одного алиаса не должно отпускать ещё удерживаемый.

## Оболочка / YOUR GAME

- Вверх/вниз или 2/8 — выбрать строку меню.
- OK или левая софт — подтвердить/запустить.
- Правая софт — назад. Из своей игры → GAMES; ещё раз → HOME.
- В примере YOUR GAME крестовина/2468 двигают sprite;5 увеличивает счётчик.
- Игровая кнопка 5 НЕ универсальный OK главного меню: действие зависит от экрана.
- Нажатие 5 в примере вызывает haptic API, но физического вибро HAL сейчас нет.

## Doom в интегрированной платформе

| Кнопка | Действие текущего адаптера |
|---|---|
| Крестовина вверх/вниз,2/8 | Вперёд/назад |
| Крестовина влево/вправо | Поворот |
|4/6| Стрейф влево/вправо |
| OK | Огонь (CTRL) и ENTER в меню; одно физическое нажатие выдаёт оба события |
| Вызов | Огонь (CTRL) |
| Левая софт | ESC — меню Doom |
| Правая софт | Возврат в GAMES с приостановкой Doom |
|5| USE/SPACE, короткий импульс после отпускания |
|0| TAB/карта, короткий импульс после отпускания |
|*| SHIFT — модификатор бега |

Возврат в меню и повторный выбор DOOM / RESUME возобновляют текущую сессию,
это не сохранение на SD. В независимом SDK Doom не связан, пункт DOOM NOT LINKED
ожидаем. Не переносить все действия демо автоматически на Doom.

### Старые экспериментальные chords — не обычные кнопки платформы

В standalone V11/V12 использовались 5+9 (cache toggle),5+# (CPU selector, НЕ
изменение PLL и не доказанные 260MHz),5+3 (полный/частичный LCD),5+0 (motor probe).
**В текущей shell-сборке вызов v11_peripheral_poll отключён через K_PLATFORM_SHELL.**
Поэтому эти комбинации не считать работающим способом управления аппаратурой.
Они могут подавлять обычные 5/0 release-импульсы: не использовать при обычной игре.
Новая диагностика вызывается отдельно из DIAGNOSTICS, не секретным chord в Doom.
Не добавлять горячие переключения частоты/питания без новой проверки.

## Управление в PC Preview

| Клавиши ПК | Телефонная клавиша |
|---|---|
| Стрелки | Крестовина |
| Enter / keypad Enter | OK |
| Q | Левая софт |
| Esc / E | Правая софт, назад |
| Space /5|5, действие |
|0..9 и соответствующие keypad цифры| Телефонные цифры |
|* / keypad Multiply|* |
|#|# |
| C | Вызов |

Удержание работает; auto-repeat не создаёт новые pressed-события. При потере
фокуса все кнопки отпускаются. Окно закрывается крестиком; Esc возвращает в меню,
а не завершает предпросмотр. Raw контакты берутся из того же C-кода authority.
