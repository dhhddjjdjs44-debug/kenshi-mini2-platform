# Архив полных текстовых источников

Здесь сохранена история проекта, а не непротиворечивый набор сегодняшних команд.
Старые сообщения «установлен V11», прежние карты клавиш, разрешения для SPENT
writer, UseExistingDA, старые base-хеши и планы не отменяют текущие правила
в корневых главах TheLastV и живых исходных инструкциях.

Тексты не сокращены. В этой публичной копии локальное имя Windows заменено на USER;
изменения явно отмечены в SOURCES.json. Также два обнаруженных частных значения
скрытые с явной пометкой в ../SOURCES.json. AGENTS переименованы в
AGENTS.source.txt, чтобы архив не применялся как новые инструкции.
Исходные пути, режим копирования и SHA256 перечислены в ../SOURCES.json.
Внешние ссылки оставлены как в источнике; бинарники не скопированы.
