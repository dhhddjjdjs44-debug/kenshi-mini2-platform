# V8: изображение появилось; затем ED02 и остановка

2026-11-19T15:02:23.053248+05:00

На обоих фото ED02 и графические артефакты. Пользователь сообщил статичный
экран, отсутствие управления и около7мин старта. Это не измеренный тайминг.

В неизменённом V8 project/src/main.c ED02 выставляется строго ПОСЛЕ возврата
RAM engine entry; затем board_halt. Код не сообщает причину возврата.
Сам engine может вернуть0 при clock/LCD/init failure либо после шага игры
при boot_mailbox.error или kenshi_doom_fatal. Значения этих полей на фото нет.
Нельзя объявлять LCD timeout/SD/allocator/CPU причиной без дополнительной проверки.

Сходные артефакты есть в MODEL_ONLY_FAT_Doom.png. Предыдущие64-frame тесты
подтверждали активность кадров и отсутствие fatal В МОДЕЛИ, не визуальную
правильность изображения/реальное управление/аппаратную скорость.

Установленный V8 NOR по-прежнему cf0e0cc4aeff8a8f74a3127a7e6bc87f414d2622e2d229c575a1affabba932f0.
Writer SPENT. Анализ не открывал USB и не менял карту/блочные устройства.
Повторное ожидание ED02 не поможет, телефон можно выключить.
Далее офлайн: воспроизвести return gate, визуальный эталон и SD read overhead.
