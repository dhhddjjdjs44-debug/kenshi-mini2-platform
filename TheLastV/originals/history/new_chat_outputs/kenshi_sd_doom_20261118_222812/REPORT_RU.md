# Kenshi Mini 2: SD → FAT → ELF → Doom

**Офлайн этап выполнен. Новая прошивка НЕ записана. DOOM.ELF — файл движка для будущего загрузчика, НЕ образ NOR/MAUI.**

## Что сделано сейчас

- Реализованы read-only FAT16/FAT32: MBR и superfloppy, 512-байтовые секторы,
  короткие имена в корне, фрагментированные файлы. GPT/exFAT/FAT12 не поддержаны.
- Потоковое чтение DOOM1.WAD: весь WAD в RAM не копируется.
  В проверке файл 4,196,020 байт, что больше проверенных 4 МиБ RAM.
- Добавлены 64 якоря цепочки на файл и отдельный 8-КиБ кэш FAT.
  Последний сквозной тест: 7,467 запросов сектора,
  5,362 уникальных секторов. Это счётчики модели, не скорость карты телефона.
- Загрузчик ELF32 ARM проверяет сегменты и entry, не позволяет писать за
  0x10000..0x400000, в MMIO или загружать W+X. BSS обнуляется, TCM mailbox
  сохраняется. При ошибке usable entry не выдаётся; повторный load запрещён.
- Добавлен отдельный legacy-MSDC CMD17 PIO-примитив для **уже инициализированной**
  карты/контроллера. Ошибки команд/CRC/данных и истечение лимита завершают работу,
  повторов и reset нет. PMIC/PLL/pinmux не изменяются. Этот примитив пока не подключён
  к аппаратному platform_sector_read: штатная заглушка возвращает ошибку.

## Что действительно проверено

**62 группы FAT/ELF + 31 группа модели MSDC = 93 группы**, строгая сборка нового C99
с -Wall -Wextra -Werror -Wconversion -Wshadow.
В неизменённом стороннем PureDOOM остаются предупреждения upstream; для него
не заявлена сборка без предупреждений.

Настоящие ARM-инструкции PureDOOM выполнились через новый C-загрузчик и C-FAT:
синтетический диск логическим размером 16 ГиБ, MBR/FAT32, фрагментированные
DOOM.ELF и DOOM1.WAD → загрузка PT_LOAD → kenshi_doom_init → **64 кадра E1M1**.
Результат кадра совпадает с ранее проверенной версией адаптера.
Проверены точные байты сегментов, BSS, сохранность TCM и живой callback ниже 64 КиБ.
Это тест выполнения/доступа/границ и ненулевого framebuffer, не эталонная проверка
всех текстур, визуальной корректности и игрового процесса.

Программный звуковой микшер выдал 8192 байта PCM, 4024 ненулевых отсчёта.
**Динамик/DAC этим не проверялись.**

Пакет исходников независимо пересобран и повторно прогнан. Его PT_LOAD совпадают
с рабочей копией, DOOM.ELF воспроизводится побайтово. 125 файлов запечатанного
предыдущего этапа проверены и не изменены. USB/flash/card operations: **0**.

## Что ещё не готово для телефона

1. Проверенные питание VMC/clock/pinmux слота и SD card enumeration/selection,
   чтение реальной ёмкости. Пользователь сообщил карту 16 ГБ; её разделы и FS
   пока неизвестны. Синтетические 16 ГиБ — тест границ адресации, не замер этой карты.
2. Аппаратный загрузочный handoff: остановка старого LCD DMA до освобождения RAM,
   размещение загрузчика/стека вне загружаемых областей, настройка clock/LCD/DMA state
   нового движка. Model prepare-hook не подтверждает аппаратную остановку DMA.
3. Компактный загрузочный MAUI-образ в прежнем разрешённом окне NOR;
   эта работа его ещё не создаёт. **Записывать storage.elf/DOOM.ELF как прошивку нельзя.**
4. Аппаратный аудиовыход. Вибро остаётся с отрицательным физическим результатом
   пользователя из предыдущей пробы; программный readback не доказывает движение.

Текущее установленное состояние не менялось: последняя проверенная CLK DIAG V3,
NOR bc942e7a3e8baa0564fd7fb0017d6665007cc5c3280904a406ac129a9f8f84e5.
Это исторический readback, новый дамп сейчас не читался. Прошивальщик не запускался.
Не форматировать карту и не менять напряжения наугад.
