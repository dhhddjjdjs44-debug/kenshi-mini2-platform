## Проверка на телефоне
1. Отключить USB, вставить аккумулятор; microSD оставить.
2. Включить обычной кнопкой, без зажатия звёздочки.
3. Снять короткое видео старта или чёткое фото последнего задержавшегося экрана.

Новая надпись `DOOM START V7`. Предыдущая V6 дошла до R_Init; игровой кадр в видео44.52сек не получен.
Причина остановки пока неизвестна. V7 фильтрует пробелы/control/punctuation прогресса и показывает строки с начальным переносом; сохраняет WAD/log/fatal hooks, не меняя файлы DOOM.ELF/WAD на карте.

При продвижении: DOOM INIT V7 / WAD IO ERROR V7 / DOOM FATAL V7.
Нужен весь экран, включая RD/OFF/PH/ERR/LBA и текст. TRACE NOT BOUND означает,
что исходные RAM DATA callback pointers не совпали; подмена не выполнена.
Hooks подключаются лишь на втором WAD callback: остановка до него остаётся
вне перехвата, поэтому D007 сам по себе всё ещё не даёт точную причину.
После первого игрового кадра startup PIO подавлен, pointers восстанавливаются
при следующем callback. Opcode patches отсутствуют. CPU/PLL/напряжения прежние.
Физический boot V7 и игровой кадр ещё не наблюдались. Hardware audio отсутствует.
Копирование/форматирование карты не нужны.

Эта попытка израсходована и не подлежит повторному запуску; физические ошибки
не разрешают автоматических повторов или расширения диапазона записи.
