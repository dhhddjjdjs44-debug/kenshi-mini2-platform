# Разработка своей игры — стартовый комплект

Открой sdk/docs/START_GAME_RU.md.
Из папки sdk запускай .\Preview-Game.ps1; свою игру пиши в apps/demo_game.c.
Это отдельный от Doom SDK и реальный ARM-код игры с тестовым HAL на ПК.

НЕ полный аппаратный релиз: customзвук/вибро отсутствуют, MHz неизвестны,
на телефоне stock, никакой прошивки/записи на SD этот комплект не выполняет.
Нет встроенного MP3 decoder, cellular, save-файлов или произвольных pluginELF.
После правки игры загрузчик pins тоже требуют пересборки, не только SD ELФ.
Внешние GCC/Python/Unicorn/pyelftools/Pillow/Tk отдельно; на этом ПК найдены.
