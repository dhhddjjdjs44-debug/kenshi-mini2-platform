## Обоснованный вывод

V2 дошла до основного экрана. Полный стартовый RAM-тест и два heap-guard
отмечены прошивкой как PASS. Один снимок не доказывает длительность реальной
работы, непрерывную анимацию, точность таймера или реакцию на нажатия.

Подготовка диагностического экрана занимает около174мс, передача/ожидание
завершения LCD около21.7мс. Сумма около195.6мс даёт около5.1кадр/с без
прочих накладных расходов — это согласуется с FPS5. На DRAW приходится
около89% этой суммы. Это не доказательство CPU26MHz: DRAW включает код,
чтение шрифта, работу с PSRAM и ожидания памяти, а не чистое число CPU cycles.
Единицы US получены делением GPT на26; внешней секундомерной сверки нет.

## Что подтверждено исходниками установленного ELF

`screen()` сначала вызывает `lcd_bars()` на все128×160пикселей, затем
`lcd_fill_rect(...,128,144,...)`, перекрывая почти всё уже нарисованное.
Это38912полусловных записей ещё ДО вывода текста. `lcd_text()` выводит
каждый символ через64pixel stores, `glyph()` выполняет линейный поиск шрифта
для каждой строки символа. Буфер CPU использует volatile uncached alias.
Поэтому 5FPS этой специально тяжёлой диагностики — не бенчмарк Doom.

BOOT/NOW совпадают в двух точках наблюдения. 1401/0000 согласуются с уже
проверяемой в LCD-init конфигурацией MPLL. `boot.c` признаёт профиль260MHz
лишь при MCU==B620, а на фотоB621; отдельный бит0 остаётся неразобранным.
Существующий reference PLL-код задаёт B620 и не объясняет отличие B621.
Недостаточно данных, чтобы объявить26 или260MHz или менять PLL наугад.

## Следующий безопасный шаг

Сначала сверить SEC внешним секундомером за60с. Затем отдельные короткие
микротесты: CPU loop в контролируемой памяти, заполнение/копирование PSRAM,
отрисовка и вывод текста по отдельности; диагностика состояния кэша.
Устранить двойную заливку и линейный поиск шрифта можно в отдельном офлайн-
кандидате, не меняя PLL/EMI/PMIC/напряжений и не трогая установленную V2.
Новая физическая запись требует нового явного разрешения и всех исходных
same-session geometry/full-before/full-after/outer/ELF проверок.
