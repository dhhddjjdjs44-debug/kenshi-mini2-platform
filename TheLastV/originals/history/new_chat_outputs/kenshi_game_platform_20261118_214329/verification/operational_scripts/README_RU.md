Это точные скрипты проведённой локальной проверки, не универсальный установщик. Они используют исходную структуру work/current_game_platform.json, локальный Python с unicorn/pyelftools, инструментальную ARM GCC, а отдельные тесты — личный исходный дамп или doom1.wad. Дамп и WAD не распространяются. Для автономной пересборки RAM ELF используйте doom/source/build.py --prefix <путь/arm-none-eabi->. Прошивка собирается firmware/project/tools/build.py с явными --prefix и --dump. Никаких физических flash-команд в этом комплекте нет.
