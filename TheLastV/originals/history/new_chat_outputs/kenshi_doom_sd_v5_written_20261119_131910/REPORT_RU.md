до D3/D5 прочитаны все 4 194 304 байта NOR и побайтно сверены с установленной V4.

## Проверка на телефоне
1. Отключить USB, вставить аккумулятор; microSD оставить.
2. Включить обычной кнопкой, без зажатия звёздочки.
3. Снять короткое видео старта или чёткое фото последнего задержавшегося экрана.

Новая надпись `DOOM SD V5`. В V4 на видео identification прошла, но FILE ERROR /
D210 означала ошибку секторного чтения до загрузки ELF. Точная причина не доказана.
В V5 оставлена низкая SD-скорость после identification вместо её повышения;
это диагностический эксперимент, НЕ доказанное исправление. CPU/PLL/напряжения
не менялись. При FILE ERROR нужно фото целого экрана: PH, CS, DS, LBA, WD, STA.
Это сохранённые значения алгоритма чтения, без дополнительных read-to-clear чтений.

При продвижении дальше: COPY ENGINE / ZERO BSS / RUN ENGINE. Число под COPY/ZERO —
адрес RAM. D006 — начало первого WAD read, D007 — успех, ED07 — ошибка этого чтения.
Загрузка с карты может быть медленнее. Первый физический игровой кадр ещё не получен.
DOOM.ELF и DOOM1.WAD прежние; копирование/форматирование не нужны.
Hardware audio не реализован. Физический boot V5 ещё не наблюдался.

Эта попытка израсходована и не подлежит повторному запуску; физические ошибки
не разрешают автоматических повторов или расширения диапазона записи.
