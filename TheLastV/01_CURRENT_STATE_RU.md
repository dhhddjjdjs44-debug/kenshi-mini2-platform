## Что означают статусы

- `not-implemented` — реализации нет.
- `implemented-unverified` — код есть, аппаратная приёмка ещё не пройдена.
- `hardware-verified` — есть конкретная проверка на телефоне с доказательством.
- `failed` — проверка не прошла; readback регистра не отменяет физический отказ.
- `MODEL_ONLY` / `PC_ONLY` — тест программной модели. Никаких заявлений о
  реальном звуке, моторе, CPU MHz или FPS из такого теста не следует.

Основная разработка прошла 78 MODEL/PC групп. Независимый SDK из архива —
70 групп: без Doom и его адаптерной проверки, без опционального медиаконвертера.
Это не 78 аппаратных тестов. Новая прошивка не установлена.
